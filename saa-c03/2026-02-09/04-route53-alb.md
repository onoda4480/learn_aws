# Route 53 と ALB の関係

## Route 53 の3つの機能

| 機能 | 説明 |
|------|------|
| ドメイン登録 | ドメイン名を購入・管理 |
| DNSルーティング | ドメイン → IPアドレスの変換 |
| ヘルスチェック | サーバーの死活監視 |

## なぜ Route 53 + ALB を組み合わせるか

```
ALBの問題：IPアドレスが動的に変わる

Route 53 でドメイン名を設定すれば、IPが変わっても関係ない
ユーザーは常にドメイン名（api.example.com）でアクセスできる
```

## ALB 単体で使うケース

| ケース | 説明 |
|--------|------|
| 内部通信 | VPC内のサービス間通信（ドメイン不要） |
| 開発/テスト | ALBのDNS名で直接アクセス |
| 他サービスの裏側 | CloudFront → ALB（ユーザーはALBを直接見ない） |

## 本番では Route 53 を使う理由

```
・覚えやすいドメイン名
・ALBを差し替えてもドメインは変わらない
・SSL証明書（独自ドメインで発行）
```
