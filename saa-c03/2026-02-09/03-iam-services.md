# SAA-C03 で出る IAM 関連サービス

## よく出る順

| サービス | 一言で | 出題頻度 |
|---------|--------|---------|
| IAM ポリシー | 権限を定義するJSON | ★★★ |
| IAM ロール | 一時的な権限付与 | ★★★ |
| IAM Identity Center | 複数アカウントのSSO | ★★☆ |
| IAM ユーザー/グループ | 人やチームに権限付与 | ★★☆ |
| IAM Access Analyzer | 外部公開リソースを検出 | ★☆☆ |

## 覚え方

```
ポリシー        = 権限の「設計図」
ロール          = サービスに「貸す」権限
ユーザー        = 人の「アカウント」
Identity Center = 複数アカウントの「入り口」
Access Analyzer = 公開リソースの「監視」
```

## 試験での判断ポイント

```
「EC2やLambdaに権限を与える」→ IAM ロール
「人に権限を与える」→ IAM ユーザー/グループ
「複数AWSアカウント」「SSO」「既存IdP」→ IAM Identity Center
「外部公開リソースを検出」→ IAM Access Analyzer
「権限の定義そのもの」→ IAM ポリシー
```
