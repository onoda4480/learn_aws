# VPC セキュリティ（ネットワークACL vs セキュリティグループ）

## 比較表

| 項目 | ネットワークACL | セキュリティグループ |
|------|----------------|-------------------|
| 適用単位 | サブネット | インスタンス（ENI） |
| 許可 | ⭕ | ⭕ |
| **拒否** | **⭕** | **❌** |
| ステート | ステートレス | ステートフル |
| デフォルト | 全許可 | 全拒否（インバウンド） |
| 評価順 | ルール番号順 | 全ルールを評価 |

## 「拒否」と「許可しない」の違い

```
許可しない（セキュリティグループ）：
  「許可リストに載ってないから通さない」
  → 「全員OK、でもこいつだけダメ」ができない

拒否（ネットワークACL）：
  「このIPは明示的にブロック！」
  → 特定のIPだけブロックできる
```

### 具体例

```
要件：基本は全員OK、でも攻撃者（203.0.113.5）だけブロック

セキュリティグループ：
  許可：0.0.0.0/0（全員OK）
  → 攻撃者だけ拒否できない ❌

ネットワークACL：
  拒否：203.0.113.5
  許可：0.0.0.0/0
  → 攻撃者だけブロック ⭕
```

## その他のVPCコンポーネント

| コンポーネント | 役割 |
|--------------|------|
| IGW | VPCとインターネットの出入り口（制御機能なし） |
| ENI | 仮想ネットワークカード（制御機能なし） |

## 試験ポイント

```
「特定IPを拒否」「ブロック」→ ネットワークACL
「許可ルールだけ設定」→ セキュリティグループ
「サブネット単位」→ ネットワークACL
「インスタンス単位」→ セキュリティグループ
```
