# 試験問題

## 問題1：DynamoDB の特徴

### 要件
- Key-Value型
- 秒間2000万リクエスト
- ストレージ容量制限なし

### 正解：Amazon DynamoDB

### 判定ポイント

```
「Key-Value」「NoSQL」→ DynamoDB
「SQL」「リレーショナル」→ RDS / Aurora
「分析」「データウェアハウス」→ Redshift
SQS はメッセージキューでありDBではない
```

## 問題2：複数リージョン + 固定IP + ALB

### シナリオ
- 複数リージョンでALB
- 固定IPアドレスでアクセスしたい（ファイアウォール要件）
- 低遅延・高可用性
- シンプルな構成

### 正解：AWS Global Accelerator

### 構成図

```
クライアント → Global Accelerator（固定IP 2つ）
                    │
         ┌─────────┼─────────┐
         ▼         ▼         ▼
       ALB       ALB       ALB
     (東京)    (米国)    (欧州)
```

### 他の選択肢がダメな理由

| 選択肢 | 理由 |
|--------|------|
| EC2で転送 | 単一障害点、運用負荷大 |
| CloudFront | 固定IPを持てない |
| NLB + ALB | 同一リージョン内のみ、複雑 |
| Elastic IP単体 | 1リージョン内でのみ有効 |

### 判定ポイント

```
「固定IP」+「複数リージョン」→ Global Accelerator
「固定IP」+「同一リージョン」→ NLB
「キャッシュ」+「静的コンテンツ」→ CloudFront
```

## 問題3：特定IPのアクセス拒否

### 要件
- インターネット上の特定IPアドレスからのアクセスを拒否

### 正解：ネットワークACL

### 判定ポイント

```
「特定IPを拒否」→ ネットワークACL（拒否ルールが設定可能）
セキュリティグループは「許可のみ」で拒否ルールを設定できない
```
