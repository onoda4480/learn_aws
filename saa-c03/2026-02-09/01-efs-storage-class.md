# Amazon EFS ストレージクラス

## 4つのストレージクラス

| クラス | アクセス頻度 | 可用性 | 料金 |
|--------|-------------|--------|------|
| Standard | 頻繁 | 複数AZ | 高い |
| Standard-IA | 低頻度 | 複数AZ | 安い |
| One Zone | 頻繁 | 単一AZ | Standardより安い |
| One Zone-IA | 低頻度 | 単一AZ | 最安 |

## 変更できるもの / できないもの

| 項目 | 変更 | 説明 |
|------|------|------|
| アクセス頻度（Standard ↔ IA） | ⭕ 自動移行 | ライフサイクルで自動 |
| 可用性（Standard / One Zone） | ❌ 変更不可 | 作成時に決定 |

## ライフサイクル管理

- ライフサイクルポリシーを**設定すれば自動**で移行される
- 移行タイミング：7日 / 14日 / 30日 / 60日 / 90日 から選択
- 再アクセス時にStandardへ戻す設定も可能

## S3との比較

| 項目 | S3 | EFS |
|------|-----|-----|
| クラス数 | 多い（Glacier系あり） | 4種類のみ |
| アーカイブ | Glacier で可能 | なし |
| 自動階層化 | Intelligent-Tiering | ライフサイクル管理 |
| 管理単位 | オブジェクト単位 | ファイル単位 |

## 試験ポイント

```
「EFSのコスト削減」→ ライフサイクル管理を有効化 + IA クラス
「単一AZでOK」「コスト最優先」→ One Zone-IA
「高可用性」「複数AZ」→ Standard
```
